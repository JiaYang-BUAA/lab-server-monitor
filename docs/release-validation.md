## Linux 稳定版前的实机验收

在可恢复的 Ubuntu/Debian 测试机上先运行 SSH dry-run，再执行配置、核对主机指纹并从管理端新建 SSH 登录；随后安装独立 Agent 和 Hub，验证启动、重启、密钥权限、受限来源、真实计算进程、采样速率以及公告/登记持久性。保留日志与失败证据。若部署非默认路径、socket 激活 SSH、容器或 hidepid，应按对应限制单独验证。

Linux GPU 当前为可选 NVIDIA 整卡指标；逐进程 GPU 显存未知。无可靠 SSH 监听归属或进程读取权限时显示未知/部分采集，不把缺失数据当作零。实时多人备注是保存后轮询同步，不是逐字同步的协同编辑器。
