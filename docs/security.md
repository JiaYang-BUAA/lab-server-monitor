# 访问与数据边界

此版本面向可信实验室内网或 VPN。网页没有账户密码登录，姓名由成员自行填写；能访问网页的人都能读取服务器状态、编辑共享公告、添加成员姓名并修改任务行的姓名和备注。这是明确的产品权限，并不表示具有服务器 SSH 权限。任务名称、预计结束时间、日志配置和释放登记仍由创建登记的浏览器会话管理。

共享公告是纯文本，最多 20,000 字符；保留换行，不执行 HTML。每次保存检查版本号，过时版本返回冲突和最新版，用户核对合并后才能保存。公告本身不提供完整版本历史，需要管理员做好 SQLite 备份。

新版本要求每次保存填写修改者姓名，并按换行分段保留未改动内容的原编辑人和时间；旧公告只有整板更新时间，迁移后不会推断逐段作者。任何能访问网页的人也可修改服务器显示名称、创建未认领任务的人工归组。人工归组只改变看板显示和认领单位，不会控制或合并实际计算进程。`/api/capacity` 是无需登录的只读瞬时建议，不是资源预约。

Hub 和 Agent 以随机 bearer token 通信。默认内网 HTTP 不加密；跨不可信网络应通过 VPN 或 [回环 Hub + HTTPS Funnel](public-access.md) 提供网页入口。不要把默认网页和 Agent 直接映射到公网。公网模式没有账号认证：公开链接的访问者均可编辑共享公告，服务器名称、资源占用、进程和登记内容也会公开。公网 API 会隐藏 SSH 来源 IP、系统账号、主机名和其他会话的日志路径。SSH 安装脚本本身不会创建公网入口。

网页没有命令执行、文件下载、停止计算或重启服务器的 API。Agent 只导出指标与必要进程属性，不输出原始命令行、环境变量、SSH 密钥或 token。可选日志估算只读显式允许目录下的受限尾部内容，返回估算与元数据，不返回原文；默认目录为空。Linux 全机进程/SSH 观察通常需要 root，Windows 监测服务使用 SYSTEM；这些权限只存在于服务端。

运行配置、授权文件、数据库、下载缓存、运行日志及实验室私有文档不可直接作为源码发布。使用 `scripts/build-release.py` 的明确文件清单生成公开包。MIT 适用于本项目代码；安装时从官方源取得的 Python、windows_exporter、Prometheus、Grafana、WinSW 保留各自许可证，本项目不把它们改授为 MIT，也不把这些二进制包含在源码包内。

发现疑似漏洞时，先在隔离环境复现并保存不含令牌的数据；发布仓库后由维护者补充私密报告渠道。SSH 公钥安装前应核对账号和来源地址，保留原会话并测试新连接，回退方式见 [SSH 配置说明](ssh-setup.md)。
